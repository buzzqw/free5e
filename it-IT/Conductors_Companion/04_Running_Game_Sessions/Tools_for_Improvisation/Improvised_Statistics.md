### Statistiche improvvisate

Ogni volta che devi improvvisare la Classe Armatura, i modificatori di attacco, le CD dei tiri salvezza o altre statistiche di combattimento per una creatura, una trappola, un oggetto o un ostacolo, usa le linee guida seguenti basate sul suo grado di sfida:

|                               |   |                            |
|------------------------------:|:-:|:---------------------------|
|                            CA | = | `12 + 1/2 GS`               |
|                            CD | = | `12 + 1/2 GS`               |
|                 Bonus di attacco | = | `3 + 1/2 GS`            |
|                          Danni | = | `7 × GS` (oppure `2d6` per GS) |
|          Tiro salvezza con competenza | = | `3 + 1/2 GS`          |
|                 Punti ferita | = | `20 × GS`                    |

Quando improvvisi le statistiche per trappole e altri oggetti che infliggono danni e possono essere attaccati per distruggerli, stima il GS dell'oggetto confrontandolo con diverse creature che producono in combattimento effetti dello stesso tipo.
