##### Una cosa sola con le ombre

**Prerequisito:**
5° livello
\
Quando ti trovi in un'area di luce fioca o oscurità, puoi usare la tua azione per diventare _[<span class="condition">impercettibile (vista)</span>](#Conditions_imperceptible)_ finché non ti muovi o non effettui un'azione o una reazione.
