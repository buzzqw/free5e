_Trasmutazione di 8° livello_

**Tempo di lancio:** 10 minuti \
**Gittata:** Te stesso (raggio di 5 miglia) \
**Componenti:** V, S, M (incenso acceso e frammenti di terra e legno mescolati nell'acqua) \
**Durata:** Concentrazione, fino a 8 ore

Devi trovarti all'aperto per lanciare questo incantesimo. L'incantesimo termina prima se non hai una visuale libera del cielo.
Finché l'incantesimo non termina, cambi le condizioni atmosferiche dell'area rispetto a quelle normali per il clima e la stagione attuali.
Scegli se aumentare o diminuire ciascuna condizione atmosferica (precipitazioni, temperatura e vento) di una fase, come indicato nelle tabelle seguenti.

___
<!-- markdownlint-disable-next-line no-emphasis-as-heading -->
_Precipitazioni (tabella)_

| Fase | Condizione |
| :----: | :----------- |
| 1 | Sereno |
| 2 | Nubi leggere |
| 3 | Coperto o nebbia al suolo |
| 4 | Pioggia, grandine o neve |
| 5 | Pioggia torrenziale, grandine battente o bufera di neve |

___
<!-- markdownlint-disable-next-line no-emphasis-as-heading -->
_Temperatura (tabella)_

| Fase | Condizione |
| :----: | :----------- |
| 1 | Caldo estremo |
| 2 | Caldo |
| 3 | Tiepido |
| 4 | Fresco |
| 5 | Freddo |
| 6 | Freddo estremo |

___
<!-- markdownlint-disable-next-line no-emphasis-as-heading -->
_Vento (tabella)_

| Fase | Condizione        |
|:----:|:------------------|
|  1   | Calma             |
|  2   | Vento moderato    |
|  3   | Vento forte       |
|  4   | Burrasca          |
|  5   | Tempesta          |

___

Ogni volta che cambi il vento, puoi anche cambiarne la direzione.
Le nuove condizioni hanno effetto dopo `1d4 × 10` minuti; a quel punto puoi cambiare di nuovo le condizioni.
Quando l'incantesimo termina, il tempo atmosferico torna lentamente alla normalità.
