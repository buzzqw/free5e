# Kit di traduzione italiana Free5e

Questa directory contiene il materiale di preparazione per la traduzione italiana
di Free5e. Il kit usa `it-IT` come codice regionale, conserva per ora i percorsi
dei file inglesi e non duplica contenuti non ancora tradotti.

## File del kit

- `glossary.csv`: glossario inglese-italiano con fonte e stato di approvazione.
- `translation_status.csv`: mappa di tutti i Markdown dei quattro documenti
  previsti.
- `dictionary.txt`: termini propri e fantastici accettati da cspell.
- `translation_notes.md`: criteri editoriali e procedura di lavoro.
- `pdf-theme.yml`: tema PDF di riferimento, impostato per il formato A4.
- `repository_study.md`: sintesi dell'architettura e dei rischi della traduzione.

I contenuti del glossario marcati `da approvare` non sono attestati direttamente
nel PDF italiano indicato e richiedono una decisione editoriale.

## Documenti previsti

- Character's Codex
- Monstrous Manuscript
- Conductor's Companion
- 5e to Free5e Migration Guide

Il glossario è stato preparato usando `IT_SRD_CC_v5.2.1.pdf` come dizionario
terminologico. Free5e include anche materiale originale e adattamenti da altre
fonti CC-BY-4.0: per questi contenuti il PDF non è considerato una fonte
vincolante.
